# Contributing Guidelines

Thank you for your interest in contributing to the Simple Interest Calculator project!

## How to Contribute

1. Fork this repository.
2. Clone the repository to your local machine.
3. Create a new branch for your changes.
4. Make your improvements or fix bugs.
5. Commit your changes with a meaningful message.
6. Submit a Pull Request for review.

## Contribution Guidelines

- Write clean and readable code.
- Follow proper coding standards.
- Test your changes before submitting.
- Provide clear descriptions of your changes.
- Be respectful towards other contributors.

## Reporting Issues

If you find any bugs or have suggestions for improvement, create an issue in the GitHub repository.

## Thank You!

Your contributions help improve this project. We appreciate your support!
